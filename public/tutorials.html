What Copilot Fusion is

GitHub Copilot Fusion is a generally available model router and orchestrator, not a single model. It combines multi-model orchestration with automatic model selection.

When you send a prompt, Copilot Fusion chooses the models and an execution pattern: one or more passes. You choose the effort level, not the pattern or the model for each pass.

Three effort levels

  • Fusion Standard: versatile models for everyday coding.
  • Fusion High: capable models for challenging tasks and deeper reasoning.
  • Fusion Max: the most capable models for demanding tasks and complex reasoning.

The live cards use High for Single and Cascade, and Max for Critique, preserving the workshop's routing choices. The router still decides which pattern actually runs. Only models enabled by your enterprise and organization policies are eligible.

Copilot Fusion is available on all Copilot plans in Visual Studio Code, the GitHub Copilot app, Copilot CLI and JetBrains IDEs. Update your client, select Copilot Fusion in the model picker, then choose an effort level. See the launch announcement and product documentation.

Three patterns

PatternWhat happensPasses you'll see
SingleOne model does the whole job.Main
CritiqueA model drafts an answer, a critic reviews it, and the same model revises it if asked.First, Critique, Revision
CascadeA model answers, a judge checks it, and a stronger model repairs it only if it fails.Main, Review, Fix-up

Revision and Fix-up only run when the review asks for changes.

How the app works

The app sends a prompt to Copilot Fusion through the Copilot SDK and shows each pass as it runs.

Each demo card sends one prompt. For Critique and Cascade, the model also gets browser tools and a demo page with accessibility problems built in. Playwright carries out the tool calls in a headless Chrome on the server. On Azure, all of this runs in one Container App; locally, it runs on your machine.

Live runs and replays

Live run

  • Starts a new Copilot Fusion session
  • Spends AIU from the server's Copilot account
  • Takes from seconds to several minutes
  • Is saved when it ends, so anyone can replay it

Replay

  • Plays back a saved run in your browser
  • Is free, because no model is called
  • Takes up to about 20 seconds
  • Uses a reference run or a saved live run

AIU (AI Units) count every token a model reads and writes. Only live runs spend them; replays and the accessibility checks are free.

Each model used is billed at its standard rate, with any applicable offer applied by Copilot. The launch announced a limited-time 30% model-cost discount for paid plans. This app displays SDK-reported usage and does not apply a second discount. Bundled recordings predate the launch and retain their original model IDs, tier labels and charges.

Workshop

Five steps, about 30 minutes. Keep the dashboard open in another tab. Steps 1 to 4 are free; step 5 spends AIU.

1. Replay a run

  1. On the Cascade card, select Replay last live run.
  2. Select Skip to the end.
  3. Read each pass: its model, how long it took, the tokens in and out, and the AIU it used. Scroll down for the answer and What it cost.

Fix-up says Not needed: the judge accepted the first answer, so the stronger model never ran.

2. See how it was routed

  1. Below the viewer, open Routing, pattern and token details.
  2. Router shows how Copilot Fusion scored the prompt. Plan shows the pattern and the model for each pass.

The prompt asks for the browser tools, so tool use scores highest. The scores come from Copilot Fusion; the app only shows them.

3. Follow the browser tools

  1. Look at the list under the Main pass. Each line is one tool call and what the model asked for.
  2. Look up each tool in the browser tools table.

The model opens the page, reads it, then measures and clicks. Only the Main pass used the browser; the Review pass judged the answer it was given.

4. Run the checks

  1. Under Accessibility checks, select Run the checks.
  2. Compare Measured now with Built into the demo page.

Eight fixed Playwright scripts measure the demo page, with no model involved. "8 of 8" means each check found its problem, not that the page passes.

5. Run it live

This spends AIU from the server's Copilot account. In a group, agree who runs it. If live runs are off, replay instead.

  1. On the Cascade card, select Run live and confirm.
  2. Watch the route, the passes and the tool calls appear. Select Stop the run to end it early.
  3. When it finishes, compare the answer with the checks from step 4. What did it find? What did it miss?

Your run may get a different route from the recording. Routing, models and prices change over time.

The browser tools

Copilot Fusion doesn't test the page itself. It asks for a browser tool, Playwright runs it in Chrome, and the result goes back to the model.

Live runs are read-only: the model can use the browser, but it can't run commands or edit files.

Try it in VS Code

  1. Run Browser: Open Integrated Browser and open the demo page.
  2. Select Share with Agent in the browser toolbar.
  3. In a new chat, select Copilot Fusion, choose High effort, and send quickly test this page with the browser tools.

This spends AIU from your own Copilot plan. Treat the result as a first pass, and still test with a keyboard and a screen reader.

GitHub Copilot Fusion is generally available. Models, prices and routing change over time, so your runs may not match the historical recordings.
